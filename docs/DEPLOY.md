# Развёртывание CCTV Cloud на любом сервере

## Требования

- Ubuntu 20.04+ или Debian 11+
- Root доступ
- Интернет (для установки пакетов и клонирования репозитория)
- Минимум 2 ГБ RAM, 20 ГБ диска
